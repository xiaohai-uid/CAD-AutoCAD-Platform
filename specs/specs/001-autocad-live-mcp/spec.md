# Feature Specification: AutoCAD 实时操控 MCP v1

> 治理原则见项目宪法；开发顺序遵循 [[2026-08-24 决策 项目开发顺序约定——契约先行+不确定性排序+双分支即规格完善]]。

## Clarifications

### Session 2026-08-24

- Q: 当 agent 连续画了多个图元后需要反悔时，撤销操作应该以什么粒度回退？ → A: 单步撤销——每次只回退 agent 最近一次成功操作产生的全部变更
- Q: 一条指令创建多个图元、中途失败时，已创建的部分怎么处理？ → A: 尽力而为——成功的保留，失败的记录原因，结果中逐项列出成败与句柄
- Q: 万级实体图纸的查询清单应按什么契约返回、性能目标多少？ → A: 分页返回——默认每页 100 条、可指定页码/页大小，首页 ≤2 秒、任意页 ≤5 秒
- Q: 会话中用户关掉又重开 AutoCAD，服务下次被调用时怎么表现？ → A: 惰性重连——发现连接失效时自动尝试重新附着一次，成功则继续，失败返回人话指引
- Q: 创建中文文字实体时未指定字高与字体样式，默认值用什么？ → A: 服务级默认——字高 3.5mm 并自动选用支持中文渲染的样式，显式参数可覆盖

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 自然语言绘图落图 (Priority: P1)

作为使用 AI 助手的工程师/设计师，我对 agent 说"画一个 100×50 的矩形，左下角在原点"，图形立即出现在我打开的 AutoCAD 当前图纸中，我能实时看到绘制过程与结果。

**Why this matters**: 这是本项目的存在理由——把"描述想法"变成"图纸上的实体"，省去命令记忆与手工坐标输入。

**Independent Test**: 打开一张空图纸 → 发出一条含明确几何参数的绘制指令 → 验证画布出现参数一致的实体，且 agent 回报的创建结果可核对。

**Acceptance Scenarios**:
1. **Given** AutoCAD 已打开且有活动图纸 **When** 用户发出"画一条从 (0,0) 到 (100,0) 的直线" **Then** 图纸出现该直线，agent 返回成功状态与该实体的句柄
2. **Given** 活动图纸 **When** 用户发出含 ≥5 个图元的一段描述 **Then** 全部落图且类型、数量、关键尺寸与描述一致
3. **Given** 中文文字内容指令（如"在 (50,50) 写'法兰盘'"） **When** 执行 **Then** 文字实体正确显示中文内容

### User Story 2 - 图层管理 (Priority: P1)

作为绘图者，我要求 agent 把不同类型的图元放到规范命名的图层上（如中心线放虚线层），保持图纸组织符合制图习惯。

**Why this matters**: 无图层的图纸不可维护；图层是工程图纸的基本素养。

**Independent Test**: 指令"新建红色虚线图层 center 并在上面画一条中心线" → 验证图层被创建且新实体归属正确。

**Acceptance Scenarios**:
1. **Given** 任意图纸 **When** 要求创建指定名称图层 **Then** 图层表出现该图层并可查询
2. **Given** 已有多图层 **When** 新建实体时指定图层 **Then** 实体归属指定图层而非当前层

### User Story 3 - 查询与反馈闭环 (Priority: P1)

作为 agent 自身，我需要能读图纸现状（有哪些实体、什么类型、在哪、什么参数），才能判断下一步画什么、避免重复与错位。没有读就没有正确的写。

**Why this matters**: agent 操作必须闭环：写之前看状态，写之后验证结果。这也是验收 US1/US2 落地质量的手段。

**Independent Test**: 画三个已知实体后发起查询 → 返回清单与已知事实完全一致。

**Acceptance Scenarios**:
1. **Given** 图纸含 N 个实体 **When** 查询实体清单 **Then** 返回数量、每个实体的类型/标识/关键几何参数，与实际一致
2. **Given** 空图纸 **When** 查询 **Then** 明确返回空而非报错

### User Story 4 - 安全网：撤销与保存 (Priority: P2)

作为绘图者，我的误操作必须可回退；成果保存时不允许静默覆盖已有文件。

**Why this matters**: agent 高频自动操作放大误操作风险；文件覆盖是数据丢失级事故。

**Independent Test**: 画→撤销→验证回到画前状态；对已存在路径执行保存 → 被拒绝并提示，显式确认后才写入。

**Acceptance Scenarios**:
1. **Given** 刚完成一次绘制 **When** 发出撤销 **Then** 该操作产生的实体全部消失，其余内容不受影响
2. **Given** 目标路径已存在同名文件 **When** 未带确认标记保存 **Then** 保存被拒绝并返回提示
3. **Given** 同上但带确认标记 **When** 保存 **Then** 成功覆盖

### Edge Cases

- AutoCAD 未运行或无活动文档时调用任何工具 → 快速返回明确错误与人话指引（如"请先启动 AutoCAD 并新建图纸"），不得挂起超时
- 会话中途 AutoCAD 被用户关闭后重新打开 → 下一次调用惰性重连成功则继续；若重开的是空白环境，工具行为视同全新会话，不虚构之前图纸的状态
- 非法参数（负半径、零长度线段、非法颜色索引）→ 校验失败并说明哪个参数不合法
- 中文图层名/中文文字内容的创建与查询往返一致
- 同一会话内连续大量操作（≥20 步）连接不失效
- 海量实体（万级）：查询按分页契约返回，首页 ≤2 秒、任意页 ≤5 秒，不因图纸变大而失效
- 多图元指令中个别图元参数非法 → 该图元失败并记录原因，其余照常落图，结果中可见逐项成败

## Requirements *(mandatory)*

### Functional Requirements

- **FR-1 连接会话**: 服务必须能附着到正在运行的 AutoCAD 实例并在其上执行操作；实例不存在时所有工具快速失败并给出启动指引。连接建立一次后会话内复用；连接失效（实例被关闭或重启）时，下一次调用自动尝试惰性重连一次——成功则无缝继续，失败则返回人话指引。
- **FR-2 基础绘图**: 提供直线、圆、弧、多段线、矩形、单行文字六类图元的创建能力，均支持指定图层与基础属性。文字实体未指定字高/样式时采用服务级默认（字高 3.5mm、中文兼容渲染样式），显式参数可覆盖。
- **FR-3 图层管理**: 创建图层（可指定颜色/线型）、列出全部图层、按名称取用。
- **FR-4 图纸查询**: 列出当前文档实体清单——分页返回（默认每页 100 条，可指定页码与页大小），每条含类型、句柄与关键几何参数；另可查询文档基本状态（是否活动、实体总数）。
- **FR-5 撤销**: 单步粒度——撤销最近一次本服务执行的成功操作，回退该次操作产生的全部实体与属性变更；不提供批量多步撤销，不透传 AutoCAD 原生撤销历史。
- **FR-6 保存**: 将当前文档另存为用户指定路径；路径已存在时必须显式确认方可覆盖。
- **FR-7 统一结果**: 所有工具返回统一结构化结果（状态/人话消息/受影响实体句柄），错误必须可被 agent 直接转述。批量创建采用尽力而为语义：部分失败不回滚已成功图元，结果中逐项列出每个图元的成败、原因与句柄。

**非目标（v1 明确排除）**: 无头 DXF/DWG 文件生成模式；AutoCAD LT 支持；3D 实体建模；尺寸标注系统；块定义与外部参照；多文档并行操控；多客户端并发。

### Key Entities *(include if feature involves data)*

- **Drawing Document（活动图纸）**: 当前操作的文档，拥有实体集合与图层表
- **Entity（图元）**: 类型、唯一句柄、几何参数、所属图层
- **Layer（图层）**: 名称、颜色、线型、可见性
- **OperationResult（操作结果）**: ok/error 状态、消息、受影响实体句柄列表

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-1**: 从发出单图元指令到图形在 AutoCAD 画布可见 ≤ 10 秒（不含 AutoCAD 冷启动）
- **SC-2**: 一段含 ≥5 个图元的自然语言描述完整落图，agent 报告的实体清单与图纸实际内容一致率 100%
- **SC-3**: 错误场景（未启动 CAD、非法参数、覆盖冲突）100% 返回人话解释与下一步建议，无超时无崩溃
- **SC-4**: 单会话连续 ≥20 步操作零连接失效、零累积性劣化；实例中途重启后，恢复在紧接着的下一次调用内完成
- **SC-5**: 撤销精确回退到上一操作前状态，不影响更早的历史内容
- **SC-6**: 万级实体图纸上查询实体清单：首页 ≤2 秒，任意翻页 ≤5 秒

## Assumptions

- 用户环境：Windows + 简体中文版 AutoCAD 2026 完整版（具备程序化自动化接口，区别于 LT 版）
- 部署形态：服务由 DSH 会话拉起，stdio 通信，单用户本机场景，无需鉴权
- **连接方式已由创始人拍板：实时附着已运行的 AutoCAD 实例**（区别于离线生成文件的路线）；具体附着机制属于技术方案范畴，在 plan 阶段定
- "实时"验收以人眼在 AutoCAD 界面看到为准
- 工具面范围参考了 GitHub 现有方案调研（daobataotie/CAD-MCP、U-C4N/Autocad-MCP 等），v1 取其交集的核心子集
