# Feature Specification: 一级圆柱齿轮减速器装配图

> 终极验收标准由视觉模型盲评打分，目标 ≥8/10（对标真实课程设计装配图）。

## 要素清单（缺一即不合格）
1. 剖视主视图：双轴线（中心距80）、阶梯轴×2、大小齿轮啮合区、轴承×4（简化画法+交叉线）、端盖×4、箱体壁与剖分面、连接螺栓组×6
2. 尺寸体系：配合尺寸（φ55H7/k6 类）≥4、中心距 80±0.031、外形尺寸（长宽高）、安装尺寸（地脚孔距）
3. 零件序号气球 ×12（圆圈+引线+阿拉伯数字，顺时针排列不交叉）
4. 明细栏 BOM：序号/代号/名称/数量/材料 五列 ×10 行
5. 技术特性表：功率/转速/传动比/中心距
6. 技术要求 ≥5 条（运转平稳不漏油、润滑、装配后空载试验等）
7. 标题栏：名称/比例/图号/设计日期

## Success Criteria
- SC-19: 实体总数 ≥400，全部经 MCP 协议落图
- SC-20: 视觉模型确认：四类要素（视图/序号/明细栏/技术要求）全部可见且无严重错乱
- SC-21: 明细栏序号与图中气球号一一对应
